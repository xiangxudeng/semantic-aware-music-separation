# 实验记录：长尾问题的诊断与可行路径

日期：2026-09-19 ｜ 对应第 2 周报告第三节

## 为什么要单独做这一轮

第 2 周前半段回答了导师的问题"长尾效果差是不是样本太少"——答案是不是。
但**现象本身没有解决**：长尾 14 类 AP 只有 0.112，是常见 36 类（0.337）的 1/3。
如果就这样进第 3 周，等于把一个没有出路的坑留给 LoRA 微调。所以把能试的路径系统试了一遍。

## 试过的四条路径

### 路径一：样本量（排除）

```powershell
python scripts/22_clap_zeroshot_official.py --split all --windows 3 --templates 4
```

评测集从 test（5,329）扩到全量（25,863），长尾 14 类正样本总量 802 → 4,817（**6 倍**），
AP 只从 0.112 动到 0.129。**无效。**

### 路径二：多模板换措辞（效果很小且不对称）

三窗单模板 → 三窗四模板：常见 36 类 +0.1147，长尾 14 类只 **+0.0310**。
说明"换说法"主要惠及头部。**不能作为长尾的主线。**

### 路径三：无监督特征后处理（全部变差，排除）

```powershell
python scripts/24_embedding_postprocess.py
```

变换只在 MTT train 的特征上拟合，全程不使用标签，仍属零样本口径：

| 配置 | 全部 AP | 长尾 AP | 长尾 AUC |
|---|---|---|---|
| none（现状） | 0.2731 | 0.1107 | 0.8092 |
| center | 0.2679 | 0.1076 | 0.8081 |
| abtt1 / abtt2 / abtt4 | 0.2367 / 0.2196 / 0.1825 | 0.1010 / 0.0936 / 0.0860 | 0.7554 / 0.7365 / 0.7041 |
| whiten | 0.1803 | 0.0734 | 0.6956 |

去均值、All-But-The-Top、PCA 白化这些在图文检索里常用的后处理，**在这里全部让指标下降**。
**排除。**

### 路径四：弱标签语义扩展提示词（有效，但主要体现在排序能力上）

```powershell
python scripts/25_weak_tag_prompts.py
```

给 8 个弱标签补同义与更具体的说法（`eastern` → "traditional Chinese music / Indian classical music /
Asian traditional music"；`baroque` → "Baroque era classical music / 17th century classical music"…），
其余 43 类保持四模板：

| 指标 | 四模板（现状） | 语义扩展 |
|---|---|---|
| 全部 AP | 0.2744 | 0.2761 |
| 长尾 AP | 0.1124 | **0.1182** |
| 长尾 AUC | 0.8081 | **0.8432** |

单标签效果最明显的是 `eastern`（AP 0.024 → 0.086，AUC 0.641 → 0.867）；
`bass` 略微下降（AUC 0.744 → 0.728），说明并非所有标签都适合扩展，需要逐个看。

## 关键一步：线性探针给出上界

```powershell
python scripts/23_linear_probe.py
```

用 MTT 官方 train 划分（18,706 条）训练多标签逻辑回归，特征直接用已缓存的官方 CLAP 嵌入，
在 test 上评测：

| 口径 | 全部 AP | 长尾 AP | 长尾 AUC |
|---|---|---|---|
| 零样本（三窗四模板） | 0.2744 | 0.1124 | 0.8081 |
| **线性探针** | **0.3765** | **0.1929** | **0.9120** |

单标签：`eastern` AUC 0.641 → **0.924**，`baroque` 0.732 → 0.966，`instrumental` 0.607 → 0.783，
`modern` 0.623 → 0.793。

## 结论

1. **长尾 AP 低，不是特征里没有信息，是零样本没把信息对齐出来。**
   只要有监督信号，一个线性分类头就能把长尾 AUC 从 0.808 拉到 0.912。
2. 因此，长尾问题的唯一大幅出路是**引入监督信号**——这正好是第 3 周 LoRA 指令微调的立足点。
3. 不引入标签的前提下，弱标签语义扩展提示词是唯一有效的一条，收益有限但方向正确，可以固化进模板。
4. **第 3 周的及格线**：线性探针在 test 上 全部 50 类 AP 0.3765、长尾 14 类 AP 0.1929。
   LoRA 微调必须超过这条线；超不过就说明大模型路线在这个任务上不如一个线性分类头，要如实写进结论。

## 局限

- 线性探针是**闭集**方案（只针对固定 50 类），与项目要做的开放词汇不是一回事，它的作用是给出上界参考。
- 弱标签语义扩展的提示词是手工写的，只覆盖了 8 类，其余标签没有系统调过。

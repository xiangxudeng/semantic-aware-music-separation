# 实验记录：FiLM 条件注入原型

日期：2026-09-19 ｜ 对应计划：W2 任务 5（压缩新增）

## 目标

第 3 周要做"语义条件分离"——把 CLAP 语义向量注入 Demucs。前一周必须先确认：
注入层本身能跑通、维度对得上、梯度不会断，而且**不能一上来就把基线模型的效果破坏掉**。

## 设计

用 FiLM（Feature-wise Linear Modulation）：条件向量 → 逐通道的缩放与平移，
`h' = (1 + gamma) * h + beta`。

两个关键决定：

1. **零初始化**：生成 gamma/beta 的最后一层权重与偏置全部置零。这样训练开始时模块是恒等映射，
   条件模型与基线逐元素完全一致。否则随机初始化会先破坏基线结果，第 3 周的对比实验就分不清
   涨跌来自条件信息还是初始化噪声。
2. **用 forward hook 注入**，不改 Demucs 的 `forward`。htdemucs 的编码器是 `ModuleList`
   且逐层调用（`encode(x, inject)`），直接替换整个 `encoder` 会直接报错；hook 只接管输出张量，
   对原结构零侵入，也顺手解决了 decoder 返回 `(x, pre)` 元组的情况。

代码：`src/separation/film.py`（`FiLM` / `ConditionedModel` / `attach_film` / `infer_channel_dims`）

## 结论

1. 注入层可用，且**零初始化这一点在真实模型上得到验证**——这正是第 3 周做对照实验的前提。
2. 通道数由 `infer_channel_dims()` 自动探测，不用手工查结构；实测的注入点通道数见
   `experiments/w2_demucs_architecture.md` 第五节。
3. 参数增量只有 1.41%，说明"加条件"这件事的代价很低；真正要花时间的是条件信息的质量。
